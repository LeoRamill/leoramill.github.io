A figure taken from the document arrives already resized by the theme's markdown image hook; one named in `image:` is served as uploaded, since a figure saved off the web is often not the format its extension claims and processing such a file fails the build. That failure is still reachable through the hook, so a figure in the body has to be a real file of its own format. Entries are grouped by year: the first of each year carries a rule above it and the year set large and grey on the right, the way an academic publication list reads. The figure, the title and the text are one hit area: the click target is a stretched overlay rather than an wrapped round everything, so a summary containing a markdown link stays valid HTML (as in the theme's own view).
