The figure is the first image of the document — whatever sits right under the title — so an entry shows one just by having one. `image:` in the front matter points at another, `image: false` drops it. A figure taken from the document arrives already resized by the theme's markdown image hook; one named in `image:` is served as uploaded, since a figure saved off the web is often not the format its extension claims and processing such a file fails the build. That failure is still reachable through the hook, so a figure in the body has to be a real file of its own format. Front matter this view reads, all optional: `authors` (a list), `authors_shown` (how many before "N more authors", default 3), `venue`, `highlight` (the coloured line: an award, an impact factor), and `buttons` (a map of label -> URL, rendered in the order below). It is called `buttons` and not `links` because `links` is the theme's own front-matter key, with a different shape. The figure, the title and the text are one hit area: the click target is a stretched overlay rather than an wrapped round everything, so a summary containing a markdown link stays valid HTML (as in the theme's own view).
